# 多手机适配版本 1.2.x

此版本优先修复搜索和筛选，不要求电脑/Appium在运行时连接手机。调试版继续免登录，尚未启用远程授权限制。

## 定位顺序

1. 获取抖音全部可交互窗口，而不是仅取活动窗口。启用非重要节点读取，避免漏掉独立面板。
2. 搜索框用已知 ID 与顶部 EditText 语义后备；取得焦点后填写关键词，并核对输入内容。
3. 筛选按分组标题、选项文字及本次布局的相对位置定位。多个“不限”以及导航栏“视频”不会混用。
4. 节点缺失或不暴露选中状态时，用随 APK 打包的中文 ML Kit OCR 在手机本地识别截图。结合新鲜控件标题与截图选项，识别红色选中状态；不上传截图。
5. 优先执行控件点击；手势只点击本次节点或 OCR 返回的实际 bounds。选项不存在时停止，不用预设比例坐标猜测筛选位置。比例滑动仅用于已确认面板内的滚动。

## 筛选与等待

每次打开筛选入口一次：等待面板 → 重置 → 逐组选择和验证 → 点击查看结果一次 → 验证面板消失且结果页出现。点击通常间隔至少 2 秒，页面切换另等 3 秒。每一步有等待上限；不因 XML 缺失而反复切换入口。

“只测试搜索筛选”执行到结果页即停止。“创建并运行”随后进入已有的视频与评论采集流程。

## 适用范围与限制

- 控件模式：Android 7.0+。截图 OCR 兜底：Android 11+，需要重新开启更新后的无障碍服务以获得截图能力。屏幕需解锁，抖音已登录。
- 已实测设备：vivo V2230A（720×1600）。未宣称其他品牌、所有抖音版本或横屏均验证通过。
- 五种布局缩放的选择器测试覆盖同名选项、导航栏同名文字、缺失/歧义条件；另有真实 OCR 标题误识别回归测试。这些测试不能替代实际多品牌测试。
- 当前抖音版本没有某个筛选条件（例如某些手机无“最多评论”）时明确停止，不静默改成其他排序。
- OCR 对分组标题允许唯一的一字误识别；对选项值仍要求精确匹配。深色主题、文字遮挡等未确认场景会停止，不能保证所有主题适用。
- 原有评论、主页和视频定位仍需随抖音版本补充真实页面测试。本次没有实现批量私信或主页自动评论。
