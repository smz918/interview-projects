# 1.3.0 私信测试版

采集页进入“客户私信 · 合并 / 多选 / 发送记录”，与采集功能在同一个 APK 中。调试版延续免登录模式，本次不部署或修改服务器。

## 记录与颜色

- 白色：未尝试。
- 蓝色：查找中或发送中。
- 绿色：发送成功。
- 红色：失败，保留具体原因；包括未找到对应抖音号、聊天限制、无法定位等。
- 橙色：可能已发送但无法确认，需手动核实；不自动重试。

状态写入本机数据库，并按抖音号关联其他任务的相同用户，重新打开软件仍保留。默认不能选中已尝试的记录；显式启用“允许重新选择失败的人”后可以重试失败者，成功与待核实仍不能选择。没有有效抖音号的人不能发送，也不按昵称推测身份。

“总数”为筛选后的评论数，“已发送”为其中历史成功的不同账号数，“合并后”为按抖音号合并的条目数；另外显示合并掉的条数和缺号条数。失败和待核实不计入已发送。历史仅在此手机跨任务复用，尚未跨手机同步。

## 队列与结果

逐个重新打开抖音，进入全局搜索，按完整抖音号查找用户，进入主页再次核对账号，再进入私信。原有草稿不覆盖。时间范围控制条目间等待、每批人数和休息时间。每日额度按发送尝试计数，包含可能已发送的未知结果。

点击发送前先记录发送尝试，防止程序中断后重复发送。成功判据是聊天界面出现比发送前更多的同文案右侧消息、输入框清空，且持续 8 秒无发送中或失败提示。这是客户端界面确认，不是送达或已读回执；无法确定则记为待核实。遇到平台验证或频率限制，停止队列。

“只检查所选用户”仅检查搜索、主页和聊天入口，不填写或发送消息，也不写入发送成功/失败历史。
